# Saraiva Mobile

Clone visual acadêmico, sem vínculo comercial com a Saraiva. Projeto em React Native com Expo, composto por oito telas e dados locais simulados.

## Telas

1. Splash
2. Login
3. Home
4. Categorias
5. Lista de livros
6. Detalhes do livro
7. Carrinho
8. Perfil

## Executar no Visual Studio Code

```bash
npm install
npx expo start
```

Depois, use o QR Code no Expo Go ou pressione `a` para Android, `i` para iOS (macOS) ou `w` para navegador.

## Funcionalidades

- Navegação entre oito telas
- Busca local por título e autor
- Filtro por categoria
- Detalhe de produto
- Favoritos
- Carrinho com soma, quantidade e remoção
- Validação simples no login
- Estados vazio e feedback visual
- Layout responsivo para celular

## Observação acadêmica

As capas são representações gráficas próprias construídas por código, evitando dependência de imagens externas. Marcas e títulos aparecem apenas para fins educacionais de prototipação.
